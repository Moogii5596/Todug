# Todug

Хүүхдийн нас, одоогийн яриа, сонирхолд тааруулж гэртээ хийх хэл ярианы дасгалын төлөвлөгөө гаргадаг платформ.

> Todug онош тавихгүй. Хичээлийн агуулгыг (`lib/content.ts`) олон нийтэд гаргахаас өмнө мэргэжлийн хэл засалчаар хянуулна.

## Боломжууд

- Имэйл, нууц үгээр бүртгүүлэх, нэвтрэх, мартсан нууц үгээ сэргээх (Supabase Auth)
- Нэг хэрэглэгч олон хүүхдийн профайл үүсгэх, засах, устгах
- Ярианы 6 түвшнээр 11 шатнаас эхлэх цэгийг сонгож, 4 долоо хоногийн мөчлөг гаргах
- Долоо хоног бүр нэг арга, өдөр бүр өөр хэвшилд (хооллох, усанд орох, хувцаслах гэх мэт) хийх нэг хувилбар
- Мөчлөг дуусахад дараагийн шатнаас үргэлжлүүлэх (гурван мөчлөг үргэлжлүүлэхийг зөвлөнө)
- Анхаарах шинж илэрвэл эмчид үзүүлэх зөвлөмж харуулах
- Хийсэн өдрөө тэмдэглэж, ахицаа хадгалах
- Хиймэл оюунаар нэмэлт тоглоом зохиолгох (сервер талын `/api/games`, нэг хэрэглэгч өдөрт 10 хүсэлт)
- Төлбөртэй багц: эхний долоо хоног үнэгүй, үлдсэн хичээл болон нэмэлт тоглоом төлбөртэй. Хэрэглэгч дансаар шилжүүлж, гүйлгээний утгад захиалгын дугаараа бичнэ (`/billing`); админ хуулгаа шалгаад төлсөн болгоно (`/admin`)
- Бүртгэлээ бүх мэдээллийн хамт устгах (`/account`)
- Нууцлалын бодлогын хуудас (`/privacy`)

## Бүтэц

| Зам | Үүрэг |
| --- | --- |
| `app/` | Нүүр, `/login`, `/reset` (нууц үг сэргээх), `/children`, `/children/[id]`, `/account`, `/billing`, `/admin`, `/privacy`, `/api/games`, `/api/lessons`, `/api/invite` |

| `supabase/migrations/` | Өгөгдлийн сангийн хүснэгт, RLS дүрэм, бүртгэл устгах функц |

## Ажиллуулах

1. [Supabase](https://supabase.com) дээр төсөл үүсгээд SQL Editor-т эхлээд `supabase/migrations/0001_init.sql`, дараа нь `supabase/migrations/0002_improvements.sql`, `0003_todug_schema.sql`, `0004_billing.sql`, эцэст нь `0005_free_limit_admin.sql`-ийг ажиллуулна. Тавууланг нь заавал ажиллуулна. Үүний дараа Project Settings > API > Data API хэсэгт Data API-г асааж, Exposed schemas-д `todug`-ийг нэмнэ (хүснэгтүүд `todug` schema-д байрладаг; үүнгүйгээр нэвтэрсний дараа «Ачаалж байна…» дээр гацна).
2. Supabase > Authentication > URL Configuration > Redirect URLs хэсэгт сайтын хаягаа `/**` төгсгөлтэй нэмнэ (жишээ нь `http://localhost:3000/**`). Баталгаажуулах холбоос `/children`, нууц үг сэргээх холбоос `/reset` руу буцдаг тул энэ хоёр зам зөвшөөрөгдсөн байх ёстой.
3. `.env.example`-ийг `.env.local` болгон хуулж, утгуудыг бөглөнө.
4. Дараах командыг ажиллуулна:

```bash
npm install
npm run dev
```

Дараа нь http://localhost:3000 хаягийг нээнэ.

## Google, Facebook-ээр нэвтрэх

1. Supabase > Authentication > Providers хэсэгт Google, Facebook-ийг идэвхжүүлж, тус бүрийн Client ID, Secret-ийг оруулна.
2. Google Cloud болон Meta for Developers дээр буцах хаягаар `https://ТӨСЛИЙН_ID.supabase.co/auth/v1/callback`-ийг бүртгэнэ.
3. Supabase > Authentication > URL Configuration > Redirect URLs хэсэгт сайтын хаягаа `/**` төгсгөлтэй нэмнэ (`/children`, `/reset` хоёулаа хамрагдана).
4. `NEXT_PUBLIC_OAUTH_PROVIDERS=google,facebook` гэж тохируулаад дахин байршуулна.

## Төлбөр

- **Үнэ, багц:** `todug.plans` хүснэгтэд. Өөрчлөхдөө: `update todug.plans set amount = 25000 where id = 'm1';`
- **Админ:** `todug.admins` хүснэгтэд имэйлээр (жижиг үсгээр). Тэр имэйлээр бүртгүүлж, имэйлээ баталгаажуулсан хэрэглэгч `/admin` хуудсыг үзнэ.
- **Хүлээн авах данс:** `lib/billing.ts`. Хүлээн авагчийн нэрийг `NEXT_PUBLIC_BANK_HOLDER` хувьсагчаар сольж болно.
- **Үнэгүй долоо хоногийн хязгаар:** нэг бүртгэлд хамгийн ихдээ 2 өөр шатыг үнэгүй нээнэ (`todug.claim_free_unit`).
- **Урилга:** админ `/admin` хуудаснаас имэйлээр урилгын холбоос үүсгэнэ (имэйл илгээхгүй, холбоосыг өөрөө дамжуулна). Хэрэглэгч холбоосоор орж `/reset` хуудсанд нууц үгээ зохионо. Үүнд Vercel дээр `SUPABASE_SERVICE_ROLE_KEY` хувьсагч шаардлагатай.
- **Түгжээ:** төлбөргүй хэрэглэгчид зөвхөн хөтөлбөрийн эхний долоо хоногийн агуулга серверээс очно. `lib/content.ts`-ийг клиент компонентоос импортолж болохгүй.
